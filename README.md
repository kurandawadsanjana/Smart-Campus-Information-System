# Smart Campus Information System

## Overview

The Smart Campus Information System is a web-based application developed using HTML, CSS, JavaScript, and Chart.js. It integrates various campus management functionalities into a single platform.

## Features

### Q1 – Student Registration & Grade Evaluation

* Student registration
* Grade calculation
* Performance remarks

### Q2 – Course Enrollment Management

* Add and manage courses
* Credit management

### Q3 – Student Records Management

* Student records storage
* Event participation analysis
* Common participant identification

### Q4 – Search & Sort Student IDs

* Sort student IDs
* Search student IDs
* Display student position

### Q5 – Fee Calculator

* Tuition fee calculation
* Hostel fee calculation
* Transport fee calculation
* Total fee generation

### Q6 – Academic Records

* Academic record management
* Report generation
* Average marks calculation
* Top performer identification

### Q7 – Directory Scanner

* File listing simulation
* Total file count display

### Q8 – Performance Analytics

* Mean score calculation
* Median score calculation
* Standard deviation calculation
* Subject-wise top performers
* Student performance visualization using charts

## Technologies Used

* HTML
* CSS
* JavaScript
* Chart.js
